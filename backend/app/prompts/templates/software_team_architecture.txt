## 输出要求

请用 **Markdown** 撰写完整系统设计文档，必须包含以下一级章节（标题可微调，但四类内容必须齐全）：

1. **系统架构** — 逻辑/物理视图、主要组件与交互（可用 Mermaid 图）
2. **技术选型** — 语言、框架、数据库、缓存、消息、部署方式及选型理由
3. **数据库设计** — 核心实体、表结构或 ER 说明、索引与关系
4. **接口设计** — 与 PRD API 对齐的服务边界、REST/内部接口、鉴权与错误约定

另可补充：非功能架构（性能/安全/可观测）、部署拓扑、风险与演进路线。

约束：
- 设计须可追溯至 PRD，不引入 PRD 未涵盖的无关系统
- 若企业架构规范与 PRD 冲突，在文末「架构决策记录（ADR）」说明取舍
- 语言与 PRD 一致
- 只输出 `architecture.md` 正文，不要寒暄
