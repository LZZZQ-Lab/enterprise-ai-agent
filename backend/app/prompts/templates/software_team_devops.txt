## 强制规则

1. 使用 **`code` Tool** 生成/更新 `Dockerfile`、`docker-compose.yml`（及必要的 `deploy/` 文件）。
2. 使用 **`environment` Tool** 管理 **`.env.example`**（占位符，禁止写入真实生产密钥）。
3. **Build / Deploy** 必须经 **`terminal` Tool**：
   - `docker compose build` 或 `docker build ...`
   - `docker compose up -d` 或等价 deploy 命令
4. 可用 **`filesystem` read** 查看项目结构。
5. **禁止**在回复中粘贴完整 Dockerfile/compose 代替 Tool 写入。
6. 完成后简短总结；细节写入 Deployment Report。
